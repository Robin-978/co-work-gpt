Inside a Language Model

看得見的 LLM：一個字是怎麼被想出來的

這一頁跑的是一個真的語言模型——一個在瀏覽器裡即時推論的迷你 Transformer。你輸入的每個字，都會實際走過 分詞 → 詞向量 → 注意力 → 前饋網路 → 取樣 → 輸出，畫面上的每個顏色格子、每條長條，都是它當下算出來的真實數值，不是示意動畫。

Step 1分詞 Tokenization

模型不認得文字，只認得數字。第一步是把輸入切成一個個 token，再用字典查出每個 token 的 id。 這個示範模型用「一個字＝一個 token」的中文字元切法；ChatGPT 這類大模型用的是 BPE，一個 token 可能是半個英文單字。

Step 2詞向量 Embedding

每個 token id 會去查一張詞向量表，換成一串數字（本模型是 48 維）。這串數字就是這個字的「意思座標」。 再加上一個只跟位置有關的向量，模型才知道誰先誰後——底下每一直行就是一個 token 的向量， 橘色為正、藍色為負、越暗越接近 0。

Step 3注意力 Self-Attention

這是 Transformer 的核心。每個字都會問前面所有的字：「你跟我有多相關？」——用 Q·K 算出分數， 再經 softmax 變成加總為 1 的權重，然後把大家的 V 按權重混合起來。 因果遮罩讓每個字只能看見自己和左邊的字（所以熱圖是下三角形）。

Step 4前饋網路 Feed-Forward

注意力負責「跟別人交換情報」，前饋網路負責「自己想一想」。它把 48 維先放大到 128 維， 用 GELU 激活函數過濾掉沒用的訊號，再壓回 48 維。多數模型有一半以上的參數都放在這裡，知識大多存在這一層。

激活值越大 = 這個「神經元」越興奮 顯示的是目前最後一個 token 在第 1 層的實際數值
等待開始…

Step 5產生下一個字 Generation

最後一層的向量會跟字典裡每一個字比對，算出分數（logits）。除以溫度後做 softmax 變成機率， 只留下最高的 Top-K 個候選，再抽籤選出一個字。溫度越低越保守（幾乎都選第一名），越高越有創意也越容易亂講。

Step 6輸出並回到第一步 Output

選中的字被接回輸入的尾巴，然後整個流程再跑一次——這就是「自迴歸（autoregressive）」。 你看到 ChatGPT 一個字一個字吐出來，就是這個迴圈在轉。
