# 使用者手冊 — 「看得見的 LLM」動態演示頁

對象：要用這一頁講解／自學語言模型運作的人。
對應檔案：`llm/index.html`（單一檔案，約 235 KB）。
模型規格：字典 755 字元、參數 134,976、2 layers × 4 heads、d=64、FFN 192、上下文 48 tokens。

---

## 1. 這一頁是什麼

一個**單檔、零後端、離線可跑**的網頁，用動畫一步一步演示語言模型從輸入到輸出的完整過程：

```
分詞 → 詞向量 → 注意力 → 前饋網路 → 取樣 → 輸出 → 回到分詞
```

**畫面上的數字都是真的。** 頁面內嵌一個從零訓練的 char-level GPT，權重直接寫在 HTML 裡，推論在你的瀏覽器即時進行。不是預錄動畫，也不呼叫任何 API — 拔掉網路線一樣跑。

**它不是什麼：** 不是聊天機器人。這個模型只有 13 萬參數、只讀過 437 句 III/V 磊晶與 SPC 的中文短句，它會做的事就是「把很像訓練語料的句子接下去」。問它今天天氣，它會用磊晶的語氣胡說八道 — 那正是要給人看的東西。

---

## 2. 怎麼打開

直接用瀏覽器開啟 `index.html` 就好，不需要架站、不需要安裝任何東西。

- 雙擊檔案，或拖進瀏覽器視窗。
- 放在網路磁碟、隨身碟、公司內網都可以；整份內容都在這一個檔案裡。
- 需要支援 `canvas` 與 ES2017 的瀏覽器（Chrome / Edge / Firefox / Safari 近幾年的版本都可以）。
- 手機可以看，版面會自己收窄（測試過 390px 寬）；但熱圖較小，投影講解建議用桌機。

若系統設定了「減少動態效果」（prefers-reduced-motion），CSS 轉場會被關掉，畫面改為直接跳到結果 — 內容一樣完整。

## 3. 畫面導覽

由上而下六個區塊：

| 區塊 | 內容 |
|---|---|
| **標題與規格列** | 參數量、層數、注意力頭、向量維度、字典、上下文 — 全部從權重檔讀出來，不是寫死的文案 |
| **控制面板** | 輸入框、開始／暫停／停止、六個範例、四個滑桿、兩個開關 |
| **步驟列（置頂）** | 六個步驟的進度指示，捲動時固定在上方；右側有產生進度與迷你暫停／停止鍵 |
| **Step 1～6** | 六個演示區塊，正在跑的那一塊會亮起來 |
| **頁尾** | 這個模型的規模、語料大小與能力邊界說明 |

步驟列的六個按鈕可以點 — 點下去會捲到對應區塊，適合講解時回頭複習某一步。

---

## 4. 五分鐘上手

1. 開啟頁面。首屏已經先靜態畫好一組預覽（用「MOCVD 的成長溫度」跑的），可以先讓聽眾看一眼六個步驟長什麼樣。
2. 按 **▶ 開始演示**（或按空白鍵）。
3. 畫面會自動捲到 Step 1，然後一路往下走到 Step 6，再回到 Step 1 產生下一個字。
4. 想停下來講解就按 **⏸ 暫停**（空白鍵）；要重來按 **⏹ 停止**（Esc）。
5. 講完一輪後，把**溫度**拉高到 1.8 再跑一次，讓聽眾看同一個提示怎麼變得語無倫次 — 這是最有效的對照。

## 5. 控制項

### 輸入提示（Prompt）

最多 40 個字。模型只認得訓練語料出現過的 755 個字元；打了字典外的字會出現橘色警告，那些字**會被略過**（不是報錯，是直接跳過）。若一個認得的字都沒有，會拒絕開始並提示你換一句。

### 三個按鈕

| 按鈕 | 作用 | 快捷鍵 |
|---|---|---|
| ▶ 開始演示 | 從頭跑一輪 | 空白鍵 |
| ⏸ 暫停 / ▶ 繼續 | 凍住動畫，畫面停在當下 | 空白鍵 |
| ⏹ 停止 | 中止並解鎖按鈕，六個區塊維持在最後狀態 | Esc |

快捷鍵在游標停在輸入框裡時不作用（否則沒辦法打空白）。步驟列右邊還有一組迷你 ⏸ / ⏹，捲到頁面下方時不用回頭找。

### 六個範例

| 範例 | 想演示什麼 |
|---|---|
| `MOCVD 的成長` | 多峰分布 — 溫度／壓力／速率三個候選都是語料裡真的接續 |
| `Cpk 大於` | 模型記得的數字，也是「幻覺」的縮影（正解機率極高，偶爾仍抽到冷門） |
| `PL 的波長` | 領域術語的接續 |
| `連續七點` | SPC 判異規則的句型 |
| `量子井的` | 幾乎沒有懸念的一格（熵 ≈ 0.03 bits） |
| `今天天氣` | 領域外輸入 — 模型會用磊晶語氣硬接，很適合講「訓練資料決定了它會什麼」 |

點範例會直接填入並開始（若正在跑則只填入）。

### 四個滑桿

| 滑桿 | 範圍 | 預設 | 說明 |
|---|---|---|---|
| **產生長度** | 1 – 200 | 36 | 要產生幾個字。提示長度 ＋ 產生長度超過 48 時，滑桿下方會提示「最前面的字會被擠出視窗」 |
| **溫度 Temperature** | 0.20 – 2.50 | 0.90 | 越低越保守（機率集中在第一名），越高越發散 |
| **Top-K 候選** | 1 – 20 | 8 | 每一步只從分數最高的 K 個字裡抽。K=1 等於永遠選第一名，結果完全固定 |
| **動畫速度** | 0.5× – 4.0× | 1.0× | 只影響動畫節奏，不影響計算結果 |

溫度與 Top-K 是**取樣**參數，改了會改變產生的字；動畫速度只改播放快慢。首屏預覽也讀同一個溫度滑桿，所以改了預設值不會跟實際演示對不起來。

### 兩個開關

- **🐢 每個字都完整演示**（預設開）：每產生一個字都完整走六個步驟。關掉後變成 **🐇 只完整演示第一個字** — 第一個字慢慢演示，之後的字用約三倍速帶過。產生長度超過 40 又開著完整演示時，滑桿下方會提醒你會跑很久。
- **🧭 自動捲動到目前步驟**（預設開）：畫面跟著目前步驟走。關掉後可以自己停在某一個區塊盯著看（例如一直盯 Step 3 的注意力熱圖，看它每產生一個字怎麼變）。

## 6. 六個步驟各在演示什麼

### Step 1 — 分詞 Tokenization

輸入被切成一個個 token，查表換成 id。chip 會逐一飛入。

**該看的：** `MOCVD` 被切成 **5 個 token**，而中文一個字只佔 1 個。英文和數字天生就比中文吃 token。

讀數列出最後 12 個 id 與字典大小。

### Step 2 — 詞向量 Embedding

三張熱圖：詞向量 ＋ 位置向量 ＝ 輸入向量。橘色是正、藍色是負、暗灰是 0（發散色標，圖例在右下）。

**該看的：** 同一個字在不同位置，第三張圖的顏色不一樣 — 位置資訊是加進去的，不是天生就有。

讀數列出最後一個字向量的前 6 維實際數值，以及詞向量表的參數量（755×64 = 48,320）。

> 熱圖最多顯示 14 個 token；序列更長時只畫最後 14 個。

### Step 3 — 注意力 Attention

T×T 的熱圖逐列畫出，右側長條列出相同數值。上方有 **2 層 × 4 頭 = 8 個按鈕**可以切換。

**該看的：**
- 右上角是空白的 — 那是未來的字，被因果遮罩擋住了，模型不能偷看後文。
- 切不同的頭，亮的位置不一樣 — 每個頭在看不同的關係。
- 讀數會直接告訴你「這個字把百分之幾的注意力放在哪個字上」。

切換頭的按鈕在暫停或停止之後仍然有效，會用最後一次的計算結果重畫 — 適合停下來逐頭講解。

### Step 4 — 前饋網路 FFN

64 維 → 192 維 GELU → 壓回 64 維，連線與激活長條分段動畫。

**該看的：** 讀數會報「有幾個神經元幾乎沒被點亮」— GELU 把它們關掉了。以及這一層的參數量（2×64×192 = 24,576），佔整個模型一大半。

> 這一格畫的是**最後一層**（第 2 層）最後一個 token 的實際數值。

### Step 5 — 產生 Generation

Top-K 機率長條 ＋ 轉盤抽籤 ＋ 亂數指針。

**該看的：**
- 長條是套用溫度之後、只留 Top-K 的機率。
- 轉盤每一段的寬度就是該字的機率；指針落在哪一段就選哪個字。
- 讀數同時給出「最高分的是誰」與「實際抽到誰」— 兩者不一定一樣，這就是為什麼同一句話每次跑結果會不同。
- 最後那個 **熵（bits）** 是這一步的不確定性，對整個字典算的：
  - `< 0.15` 幾乎沒有懸念
  - `< 1` 有點猶豫
  - `< 2.5` 相當不確定
  - 更高 = 完全不知道要接什麼

把溫度拉高再看同一格，熵會明顯變大 — 這是溫度在做什麼最直觀的證據。

### Step 6 — 輸出 Output

新的字接回輸入，箭頭閃一下，回到 Step 1。這就是自迴歸生成：`P(下一個字 | 前面所有字)`。

## 7. 常見情況

| 現象 | 原因與處理 |
|---|---|
| 出現橘色警告「以下字不在字典裡」 | 這個模型的字典只有 755 個字元，只涵蓋訓練語料用過的字。那些字被略過了，其餘照跑。換一句範例即可 |
| 按了開始卻沒反應，只出現警告 | 整句話沒有任何一個字在字典裡。用上面的範例句 |
| 跑很久跑不完 | 產生長度拉太大又開著「🐢 每個字都完整演示」。切成 🐇 或把動畫速度調到 4× |
| 產生到一半開頭的字不見了 | 上下文只有 48 tokens，超過就會往前滑動、開頭被擠出視窗。滑桿下方會事先提醒 |
| 每次跑結果都不一樣 | 正常。Step 5 是隨機抽樣。想要固定結果就把 Top-K 設成 1 |
| 內容明顯是胡說 | 也是正常的，而且是重點之一。13 萬參數、45,780 字語料的模型只會生成「很像訓練資料」的句子 |
| 熱圖只顯示一部分 token | 熱圖上限 14 個 token，長序列只畫最後 14 個 |
| 動畫不流暢 | 調低動畫速度，或關掉自動捲動 |

## 8. 這個模型的邊界（講解時值得先講清楚）

- **只會這個領域。** 語料是 437 句、45,780 字的 III/V 磊晶 ＋ SPC ＋ 良率可靠度 ＋ 金融財經中文短句。領域外的輸入它會硬接。
- **會記錯數字。** 例如偶爾吐出 `Cpk 大於 1.63`，而正確數字在那一格有 97.5% 的機率 — 是 0.2% 的候選贏了抽籤。這正是「幻覺」的縮影：不是不知道，是抽樣抽到了冷門。
- **有些歧義訓練不掉。** 例如「複利是利息」下一格，`，` 58.8% 對上 `再` 31.0%（正解是「再」）。char-level ＋ 48 tokens 的前綴訊息量壓不過「利息 → ，」這個先驗，多訓練也不會改善。
- **規模差距。** 這個模型 13 萬參數；真正的 LLM 是十億到兆級。演示的是**機制**，不是能力。
